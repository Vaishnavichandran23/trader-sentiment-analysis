# Trader Performance vs Market Sentiment

## Objective
Analyze how Fear vs Greed sentiment affects trader performance.

## Steps
- Data cleaning and merging
- Feature engineering
- Analysis and segmentation

## Insights
- Traders perform better during Greed
- Trade size increases in Greed (higher risk)
- Frequent traders show volatile performance

## Strategies
- Reduce trade size during Fear
- Avoid overtrading during Greed
